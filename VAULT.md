# GoreeCloud Vault Product Family

## Canonical identity

**GoreeCloud Vault** is the single current product identity for GoreeCloud's credential and encrypted-vault platform.

The canonical family is:

- GoreeCloud Vault
- GoreeCloud Vault Server
- GoreeCloud Vault Web
- GoreeCloud Vault Browser
- GoreeCloud Vault Desktop
- GoreeCloud Vault Mobile
- GoreeCloud Vault CLI

The former product identity **GoreeVault** is retired. Historical records may retain that name only when necessary to preserve chronology, old releases, commits, migration evidence, compatibility identifiers, or other immutable historical facts. Historical use must not imply that GoreeVault remains a current product or alternate brand.

## Server role

GoreeCloud Vault Server is the dedicated synchronized backend. It provides authenticated APIs, authorization, persistence, synchronization, organizations and collections, attachments, recovery-supporting state, and compatibility behavior while protected vault contents remain client-encrypted where required by the zero-knowledge model.

## Native-development boundary

The long-term product architecture must be original GoreeCloud-owned software. The inherited Vaultwarden-derived runtime is transitional and may remain only where continuity, migration, interoperability, recovery, or security requires it while GoreeCloud-native replacements are developed and accepted.

Mature cryptography, protocol implementations, database engines, runtime facilities, and similar narrow foundations may remain when replacement would materially increase security or interoperability risk. This exception must not preserve upstream product architecture, branding, UI, workflows, or general product logic as the permanent GoreeCloud application.

## Compatibility-sensitive legacy identifiers

Internal identifiers containing `goreevault` or `vaultwarden` may remain temporarily when changing them would create unnecessary migration, evidence, interoperability, data-integrity, user-preference, or security risk. They must be treated and documented as legacy implementation details rather than current product identity.

Current user-facing presentation, documentation headings, product listings, artwork, transactional presentation, and newly created public identifiers must use the GoreeCloud Vault family names.

## Platform requirements

GoreeCloud Vault and GoreeCloud Vault Server remain subject to GoreeCloud Manager, Privacy Shield, Wardveil Security, Everkeep, Glaze UI, GoreeCloud Mesh, and GoreeCloud Identity according to their applicable authority boundaries. Conformance must be proven by implementation and evidence; naming alone establishes no security, privacy, recovery, identity, or Stable claim.
